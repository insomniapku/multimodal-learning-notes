## 1. 模态、多模态与人类交流

### 1.1 两种不同的“多模态”（第 6–10 页）

统计学中的 **multimodal distribution（多峰分布）** 指概率密度函数具有多个局部极大值。这里的 mode 是“峰”，与多模态学习中的信息模态含义不同。

![概率密度的多个峰：一维与三维示意](../assets/ch01/p006-probability-modes.jpg)

**Modality（模态）** 指信息的类型、获取信息的方式，或者信息的存储与表示形式。感官模态是视觉、触觉等主要感觉形式，也可理解为信息交流的通道。

| 模态 | 课件举例 |
| --- | --- |
| 自然语言 | 口语、书面语 |
| 视觉 | 图像、视频 |
| 听觉 | 语音、其他声音、音乐 |
| 触觉 | 接触、触感 |
| 其他感官与运动 | 嗅觉、味觉、自身运动 |
| 生理信号 | 心电图 ECG、皮肤电导 |
| 其他成像或传感信息 | 红外图像、深度图像、功能磁共振 fMRI |

第 7 页的感官图将外观、声音、触觉、味觉、气味与注意力、记忆、偏好联系起来：人的理解既依赖输入通道，也依赖已有认知状态。

### 1.2 多模态交流行为（第 8 页）

| 交流通道 | 具体信息 |
| --- | --- |
| 视觉行为 | 头部、眼部、手臂手势；身体姿势；人际距离（proxemics）；头部朝向与视线；微笑、皱眉等表情 |
| 言语内容（verbal） | 词汇；词性等句法信息；话语行为等语用信息 |
| 发声方式（vocal） | 语调、音质等韵律；笑声、呻吟等声音表达 |

“说了什么”和“怎样说”是不同的信息来源。相同词句可以通过语调、表情和姿态表达不同情绪。

## 2. 多模态研究的历史与动机

### 2.1 四个研究时期（第 12–17 页）

| 时期 | 时间范围 | 研究重点与课件实例 |
| --- | --- | --- |
| 行为研究时期 | 1970 年代至 1980 年代末 | 研究人类跨感官感知；McGurk 效应（1976）说明看到的口型会影响听到的语音 |
| 计算研究时期 | 1980 年代末至 2000 年 | 视听语音识别 AVSR；多模态／多感官交互界面；情感计算 |
| 交互研究时期 | 2000–2010 年 | 对人类多模态交互进行建模；会议理解、认知助手 |
| 深度学习时期 | 2010 年代起 | 从手工特征走向表征学习、视觉注意力及多模态基础模型 |

**McGurk 效应**：视听信息在感知过程中相互作用，语音识别并非仅由音频决定。课件引用 McGurk 与 MacDonald 的论文 *Hearing lips and seeing voices*，Nature，1976。

**视听语音识别（AVSR）**：联合使用声音和口唇运动。第 14 页用词错误率与信噪比的关系说明，在噪声较强的条件下，视觉信息能补充音频信息；图中的特定系统展示了约 10 dB 的增益，不能把这一数值泛化为所有 AVSR 系统。

![音频识别与视听识别在不同信噪比下的词错误率](../assets/ch01/p014-avsr-noise.jpg)

**情感计算**：课件借 Rosalind Picard 的观点说明，自然交互需要识别、理解并表达情绪。这里保留研究动机，不保留书籍封面装饰。

**AMI 项目**（IDIAP，2001–2006）：100 多小时会议录制数据，音视频完全同步，并提供转写与标注。

**CALO 项目**（SRI，2003–2008）：名称为 Cognitive Assistant that Learns and Organizes；与 Personalized Assistant that Learns（PAL）相关。课件指出 Siri 是该项目的衍生应用。

深度学习时期的代表工作：

- *Multimodal Deep Learning*，ICML 2011。
- *Multimodal Learning with Deep Boltzmann Machines*，NIPS 2012。
- *Show, Attend and Tell: Neural Image Caption Generation with Visual Attention*，ICML 2015。
- 多模态基础模型（Multimodal Foundation Models）。

推动因素包括大规模多模态数据集、更快的计算机与 GPU、高层视觉特征、向量化语言特征。

### 2.2 为什么需要多模态学习（第 19–22 页）

人通过视觉大量地感知世界，通过语言大量地交流和传递知识。多模态学习希望模型同时具备 **感知与交流** 的能力：既能看懂，也能理解与生成语言。课件以 ResNet 代表视觉理解、BERT 代表语言理解，将二者指向多模态智能。

```mermaid
flowchart LR
  V[图像、视频、传感器] --> VE[视觉表征]
  L[语言、语音] --> LE[语言与声音表征]
  VE --> M[表征、对齐与融合]
  LE --> M
  M --> U[理解与推理]
  M --> G[跨模态生成]
  M --> A[导航与动作]
```

第 20–21 页的任务演进图包含：视听语音识别、基于内容的视频检索、情感识别、视频事件识别、多模态情感分析；随后扩展至图像描述、视频描述与定位、视觉问答、视频问答与指代表达、跨模态对话、大规模视频事件检索、视觉语言导航、自动驾驶，以及图像到文本／视频的生成。

## 3. 典型任务与完整例题

记 $`V`$ 为视觉信息，$`L`$ 为语言信息，$`A`$ 为动作。箭头描述输入与输出的模态关系；$`V`$ 可包括图像、视频或输出的视觉区域。

| 任务 | 输入与输出 | 核心要求 |
| --- | --- | --- |
| 图像描述 | $`V\to L`$ | 概括整张图像 |
| 密集图像描述 | $`V\to L`$ | 对多个区域分别生成描述 |
| 视频描述 | $`V\to L`$ | 理解动作与时间顺序 |
| 指代表达定位 | $`V+L\to V`$ | 根据语言定位目标区域 |
| 视觉问答 | $`V+L\to L`$ | 对图像中的问题作答 |
| 视觉对话 | $`V+L\to L`$ | 结合图像与多轮历史作答 |
| 视频问答 | $`V+L\to L`$ | 结合视频、事件顺序和可能的字幕作答 |
| 视觉常识推理 | $`V+L\to L`$ | 选择答案并给出合理依据 |
| 文本生成图像 | $`L\to V`$ | 将属性、关系和构图落实到图像 |
| 视觉语言导航 | $`V+L\to A`$ | 根据环境观察与指令行动 |
| 自动驾驶多模态导航 | 课件简写为 $`V+L\to A`$ | 融合相机、激光雷达、雷达与地图等信息 |

## 4. 单模态理解的困难

### 4.1 计算机视觉（第 43–50 页）

目标是跨越 **像素与语义之间的差距**。计算机得到像素数值阵列，需从中恢复对象、场景和意义。

| 挑战 | 为什么困难 | 课件示例 |
| --- | --- | --- |
| 视角变化 | 同一对象从不同视角看，投影形状不同 | 雕塑的多个视角 |
| 光照变化 | 亮度、阴影会大幅改变像素 | 不同光源照射下的企鹅 |
| 尺度变化 | 对象在图像中的大小变化 | 成人与儿童持笔记本电脑 |
| 形变 | 同一对象可有不同姿态和轮廓 | 奔跑的马 |
| 遮挡 | 部分对象不可见 | 被树干遮挡的人与马 |
| 背景杂乱 | 对象特征与背景混淆 | 融入复杂花纹背景的形象 |
| 类内差异 | 同一类别内部外观差异很大 | 不同结构、材质的椅子 |

### 4.2 自然语言处理（第 51–54 页）

**多语言性**：不同语言有不同词汇、句法与表达习惯。

**歧义例题一：**“I made her duck.” 可理解为：

- 我让她蹲下／低头躲避。
- 我给她做了鸭肉。
- 我把她养的鸭子做成了菜。

歧义来源：duck 是名词还是动词？make 是“烹调”还是“使某人做某事”？her 是“给她”还是“属于她的”？

**歧义例题二：三类歧义。**

| 类型 | 例句 | 需解决的问题 |
| --- | --- | --- |
| 结构歧义 | I eat sushi with tuna / I eat sushi with chopsticks | with 表示食物成分还是工具？ |
| 词义歧义 | I went to the bank | bank 是银行还是河岸？ |
| 指代歧义 | John saw Jim. He was drinking coffee. | He 指 John 还是 Jim？ |

**泛化例题：**“I made her duck cassoulet.” Cassoulet 是法国豆类炖菜。模型总会遇到陌生词汇和结构，必须从训练样本泛化到实际使用场景。

## 5. 多模态学习的五项核心挑战

第 55–73 页主要采用“表征、对齐、转换、融合、协同学习”五项划分。第 55 页另列出新版综述的六项框架；应保留这一分类差异，不能将不同综述混成同一个定义。

### 5.1 表征 Representation（第 56–58 页）

学习如何表示和概括多模态数据，以利用模态间的 **互补性与冗余性**。

- **联合表征（joint representation）**：多个模态共同映射到一个表征。
- **协调表征（coordinated representation）**：各模态分别表示，通过约束或映射使其可比较、可联系。

![联合表征与协调表征的区别](../assets/ch01/p058-joint-coordinated.jpg)

图像、词句（如“Wow!”、“I like it!”）、欢乐或紧张的语气可被映射到具有共同语义的向量空间。

**多模态向量运算例题**（Kiros 等，2014）：

```math
\mathbf e_{\mathrm{新语义}}
\approx \mathbf e_{\mathrm{图像}}
-\mathbf e_{\mathrm{旧属性}}
+\mathbf e_{\mathrm{新属性}}.
```

该式是对课件示意图的符号化整理。图中通过最近邻检索展示：蓝车减蓝加红得到红车；减蓝加黄得到黄车；黄公交减黄加红得到红公交；白衣减白加红得到红衣；白天建筑减白天加夜晚得到夜景；飞机减飞行加航行得到船；碗中猫减碗加盒子得到盒中猫；盒中猫减盒子加碗得到碗中猫。关键是视觉内容与语言属性在嵌入空间中形成对应关系。

![视觉语义向量加减与最近邻图像检索](../assets/ch01/p057-embedding-arithmetic.jpg)

### 5.2 对齐 Alignment（第 59–63 页）

识别两个或多个模态中元素或子元素之间的直接对应关系。

- **显式对齐**：重新对齐不同步的数据，能够估计对齐代价。例如把动作姿态序列与视频帧对应起来。第 60–61 页展示骨架与视频的不同步及重新匹配过程。
- **隐式对齐**：在内部学习潜在对应关系，以帮助完成任务。例如句子“一只含着网球的狗在浑浊的水中游泳”里的 dog、tennis ball、dog swimming、murky water，分别联系对象区域、球、动作及水域。

![显式对齐：动作姿态与图像序列的匹配](../assets/ch01/p060-explicit-alignment.jpg)

![隐式对齐：句子片段与图像子区域](../assets/ch01/p062-implicit-alignment.jpg)

**视频定位（Video Grounding）**：输入视频和句子查询，输出目标片段的开始及结束时间戳。该任务把语言语义落实到视频的时间区间，而非只输出一句描述。

### 5.3 转换 Translation（第 64–68 页）

把一个模态的数据转换为另一个模态；这种对应关系通常具有开放性或主观性，一段文字可能对应许多合理图像或动作。

### 5.4 融合 Fusion（第 69 页）

联合两个或更多模态的信息，完成一个预测任务。课件融合图涉及对象、场景、动作、人脸、OCR、语音及其他音频特征，经视觉／文本查询编码进入联合嵌入空间；另一个例子联合文本、视频与声音预测情绪。

**对齐**回答“哪些内容对应”；**融合**回答“怎样联合信息作预测”；两者可以出现在同一模型中。

![视觉、文本、语音及情绪信号的融合示意](../assets/ch01/p069-multimodal-fusion.jpg)

![识别连接器以及解释反常视觉场景](../assets/ch01/p091-visual-understanding.jpg)

**例题：测辐射热计的导热杆温度分布。**输入包含法文题目、结构图和文字指令，模型需要联合读图与推导。

题目背景：吸收器接受辐射功率 $`P_r`$；温度由电阻 $`R(T)`$ 测量，电阻温度系数为

```math
\alpha=\frac{1}{R}\frac{dR}{dT}.
```

系统热容为 $`C_{th}`$；均匀导热杆长 $`L`$、截面积 $`S`$、导热率 $`\lambda`$，无侧向热交换，连接吸收器与温度固定为 $`T_b`$ 的恒温器。

稳态下，导热杆温度满足

```math
\frac{d^2T}{dx^2}=0,
\qquad T(0)=T_0,\quad T(L)=T_b.
```

积分两次得 $`T(x)=C_1x+C_2`$；代入边界条件得到

```math
C_2=T_0,\quad C_1=\frac{T_b-T_0}{L},\qquad
\boxed{T(x)=T_0+\frac{T_b-T_0}{L}x}.
```

因此温度沿杆呈线性变化。课件给出的解答止于此温度分布。

![测辐射热计题目、结构图及温度分布推导](../assets/ch01/p092-bolometer-example.jpg)
